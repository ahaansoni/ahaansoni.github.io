how this site is built

colophon

Hand-coded, no build step

One HTML file, no framework, no bundler, no JS dependencies. Just modern browser primitives the way a backend engineer ships a personal site. Deployed straight from a GitHub repo.

Markup Semantic HTML · single-file layout, no templating engine
Styling Vanilla CSS · custom properties for theming, color-mix(), CSS Grid, dashed borders, SVG noise texture
JS Plain JavaScript · ~50 lines, no libraries. IntersectionObserver for scroll reveals, fetch API for the form, localStorage for theme persistence
Typography Fraunces serif, JetBrains Mono, Geist — all via Google Fonts
Hosting GitHub Pages · free, auto-HTTPS via Let's Encrypt, deployed on git push
Contact form Formspree · async fetch submission, honeypot field for spam, in-place status messages
Analytics Umami · privacy-friendly, no cookies, no personal data, GDPR-compliant
Source github.com/ahaansoni · open for you to fork
