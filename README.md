## About this repo

This is the source code for my personal portfolio site — a single-file, hand-coded site deployed on GitHub Pages. No framework, no build step. Just HTML, CSS, and ~50 lines of vanilla JS.

If you're a recruiter or hiring manager, the live site has my full experience, projects, and tech stack. If you're a developer who likes the look of the site, feel free to fork as a starting point for your own — just swap the content.

---

## Tech

- **Markup:** Semantic HTML, single-file
- **Styling:** Vanilla CSS with custom properties, `color-mix()`, CSS Grid, SVG noise texture
- **JS:** Vanilla JavaScript — IntersectionObserver, fetch API, `localStorage`
- **Typography:** Fraunces, JetBrains Mono, Geist (via Google Fonts)
- **Hosting:** GitHub Pages
- **Contact form:** [Formspree](https://formspree.io)
- **Analytics:** [Umami](https://umami.is) — privacy-friendly, no cookies
